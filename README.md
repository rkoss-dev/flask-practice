# Project Overview

This project uses a uv created python environment to work with relational databases. This project utilizes Flask, Marshmallow, SQLalchemy, and MySQL to create a fully functional e-commerce API that manages users, orders, and products. This is a RESTful API with CRUD endpoints. Postman and MySQL Workbench were also used to check functionality. The Postman collection that tests all endpoints is included in the repository for your convenience.

## Steps for viewing this project

1. Clone or download the repository to a folder in a chosen location.
2. Open the files in an IDE or text editor of your choosing for review.
3. You may run the `main.py` script in the terminal or within a IDE of your choosing. Ensure you are able to satisfy all dependencies listed in `pyproject.toml` for proper function.
